# CarPlay-only suppression of the legacy cluster satellite logo

Status: installed and explicitly confirmed permanent by the user on 16 November 2026.
CarPlay without the legacy Google logo is physically confirmed. OEM fallback output
is observed in the transition log; repeated cold/sleep starts remain unverified.
See `docs/SATELLITE_CLUSTER_LOGO.md` for firmware evidence and remaining uncertainty.

The probe replaces one outgoing `CombiBAPServiceNavi.updateMapView(int,int)`
call inside the existing zoom-patched `CombiBAPListener.updateMapView()`.
It does not change the saved OEM `mapView`, supplementary view, zoom handlers,
guidance, native capture, startup files, tiles, or copyright text.

Opt-in: `-Dconnectwow.carplay.satelliteLogo=hide-during-carplay`.
Without this JVM option the outgoing BAP values pass through unchanged.
With it, a worker checks the existing checksummed renderer lease every 500 ms.
Only original satellite value1 is sent as0 while that lease is valid. On lease
loss/OEM fallback, the latest OEM value is restored. No file reads in the BAP
callback; no constructor-started thread. Failed worker transitions retry.

## Build

Run `build-tools/build_satellite_logo_probe.py --zoom-jar <verified-source.jar>
--expected-sha256 <exact-source-hash> --jdk <jdk-bin-directory>` on one line.
Output: `build/PorscheCarPlayZoomLogo.probe.jar` and its JSON manifest.
The builder verifies stack bytecode and legacy helpers and checks all unrelated
classes are byte-identical. The source zoom JAR is not modified.
Do not add this beside a competing zoom JAR: it contains the same OEM class.

## Tests

Set JAVA_HOME to the local JDK root, then run:
`python -m pytest tests/test_satellite_logo_probe.py tests/test_guidance_processing_boundary.py -q`
